#   기동 단계에서 TypeError로 앱이 죽음. 호환되는 마지막 계열로 제한함.
#
# pandas/numpy/plotly는 버전을 고정하지 않음
#   배포 환경이 Python 3.14인데 특정 구버전은 3.14용 빌드가 없어
