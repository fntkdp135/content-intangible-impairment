# 콘텐츠 무형자산 손상징후 분석

엔터·미디어·콘텐츠 상장사의 **무형자산 손상차손을 DART 사업보고서 주석에서 추출**해
데이터셋을 구축하고, 재무데이터로 손상 인식을 예측할 수 있는지 검증한 프로젝트임.

**결론부터** — 예측 모델은 성립하지 않았음. 재무제표 수준 데이터로는 '직전 손상 이력'을 넘어서는
예측력을 확보할 수 없었음. 손상 인식은 재무비율로 환원되지 않는 경영진 재량의 영역이며,
이것이 감사인의 전문가적 판단이 필요한 이유라는 결론에 도달함.
지표·임계값을 조정해 성능을 좋아 보이게 만들지 않고 음성 결과로 확정함.

---

## 1. 문제의식

- 감사에서 다루기 어려운 것은 '사실'이 아니라 '추정'임. 무형자산 손상은 경영진의 미래현금흐름
  가정에 따라 금액이 달라짐
- K-IFRS 1036은 매 보고기간말 손상징후 검토를 요구하나 1차 판단 주체가 경영진임.
  따라서 **손상을 인식하지 않기로 한 결정은 회계처리 기록에 남지 않음**
- 엔터·미디어는 콘텐츠제작비·판권의 자산 비중이 크고, 제작비 투입과 수익 실현 사이에 시차가
  있으며, 손상 인식이 당기순손실로 직결되어 **인식 시점을 늦출 유인이 명확함**

**연구질문**: 손상차손이 인식되기 이전 연도의 재무데이터만으로 그 인식을 예측할 수 있는가?

## 2. 데이터 확보 — 이 프로젝트의 실질적 성과

### 본문 API로는 정답 레이블을 만들 수 없음

DART 재무제표 API(`fnlttSinglAcntAll`)로 손상차손을 받으려 했으나 절반도 잡히지 않았음.
원인은 **표시 방식**이었음 — 하이브·스튜디오드래곤 등은 현금흐름표를 `영업으로부터 창출된 현금`
한 줄로만 표시하고 상각비·손상차손 등 조정항목을 전부 주석으로 뺐음.

더 큰 문제는 **결측이 무작위가 아니라는 것**이었음. 조정항목을 생략한 쪽이 전부 대형사여서,
본문만 쓰면 소형사만으로 학습한 모델이 됨. 같은 회사도 연도별로 표시 방식이 바뀜.

### 해결 — 재무상태표를 기준점으로 삼는 2점 대사

사업보고서 원문(`document.xml`)의 무형자산 주석 변동표를 파싱하되,
**기말 장부금액 = 당기말 잔액**이면서 **기초 장부금액 = 전기말 잔액**인 표만 채택함.
단위(원/천원/백만원)도 어느 배수에서 일치하는지로 역산함.

이 방식으로 당기/전기 혼동, 연결/별도 혼동, 단위 오인, 취득원가/장부금액 혼동이 한꺼번에 걸러짐.
맞지 않는 표는 채택하지 않고 '실패'로 명시해, 검증되지 않은 값을 성공으로 위장하지 않음.

### 파서 개선 이력 (시범 10개사 · 50 firm-year)

| 단계 | 레이블 확보율 | 해결한 문제 |
|---|---|---|
| 재무제표 본문 API | 0% | 대형사가 조정항목을 주석으로 빼 확보 불가 |
| 키워드 검출 + 기말 대사 | 60% | 표를 키워드로 고르고 기말잔액만 맞춤 |
| 느슨한 검출 + 2점 대사 | 80% | 기초=전기말까지 함께 대사 |
| 표 헤더 인식 보정 | 90% | `(단위: 천원)` 행을 헤더로 오인해 금액이 2배가 되던 문제 |
| 정정보고서 폴백 | **96%** | 정정본에 주석이 없는 경우 원본으로 재시도 |

진단 과정에서 실제로 발견한 함정들

- `대손상각비`가 '손상' 부분일치에 걸려 들어옴 — 매출채권 관련이므로 반드시 배제
- 표 첫 행이 `(단위: 천원)` 안내문인 경우 이를 헤더로 오인하면 합계 열을 못 찾아
  모든 열을 더하게 되고 **금액이 정확히 2배**가 됨 (하이브 5개 연도 전부 이 원인)
- `[기재정정]사업보고서`는 고친 부분만 담아 무형자산 주석이 통째로 없을 수 있음

## 3. 모집단

- DART 전 상장사 3,981개사의 업종코드를 수집(1회 배치 후 CSV 캐시)
- 핵심 대역: 영상·방송프로그램 제작/배급 591, 음반 592, 방송 60x, 창작예술 90x → 72개사
- 웹툰·웹소설 IP 6개사 추가 (콘텐츠 자산화·상각 구조가 드라마·영화와 동일)
- 게임(582x) 제외 — 개발비 자산 성격이 다름
- **상장폐지 기업도 포함** — 사라진 기업을 빼면 생존편향으로 정작 위험했던 사례가 누락됨
- 최종 **78개사 / 2015–2025 사업연도 / 661 firm-year**

### 폐기한 설계 — 무형자산 비중 게이트

당초 "무형자산/자산총계 5% 미만이면 적용 대상 아님"으로 걸러려 했으나, 실제로 재보니 이 비율은
콘텐츠 자산 집약도가 아니라 **영업권 비중**을 재고 있었음.
와이지(4.1%)·쇼박스(2.4%)는 탈락하고 네이버(8.3%)·카카오(18.8%)·축산물 유통업체(7.3%)가 통과함.
핵심 업종 72개사 중 51%가 미달로 나온 것 자체가 판별력이 없다는 증거여서 필터에서 제외함.

## 4. 데이터 검증

- **결측 편향 점검**: 연도별 대사 성공률은 72–81%로 평평했으나, 규모별로는
  대형 95.7% vs 소형–중대 78–82%로 **편향이 잔존**함(한계로 명시)
- **연결/별도 전환**: 22개사 30 firm-year에서 발생. 무형자산이 15억→185억으로 뛴 것이
  실제 증가가 아니라 기준 변경인 경우가 있어 해당 구간은 증가율 계산에서 끊음
- **손상액 원표 대조**: 손상액/무형자산이 1을 넘는 상위 6건을 원표와 대조해 확인.
  5건은 기중 전액 손상의 정상 사례였고, 1건(신뢰도 '보통' = 기말만 대사)이 유형자산 표에
  오매칭됨 → **1점 대사 건 53건을 표본에서 제외**
- 최종 분석 표본 **390 firm-year / 56개사**, t→t+1 학습쌍 322건

## 5. 가설검정

| 가설 | 변수 | 결과 |
|---|---|---|
| H1 자산은 쌓이는데 수익이 안 따라오면 손상 위험 | 무형자산증가율 − 매출성장률 | **기각** (p=0.39–0.78) |
| H2 상각을 늦추면 비용 이연이고 뒤에 손상으로 터짐 | 유효상각률과 그 변화 | 기각 |
| H3 이익의 질이 나쁘면 손상 인식이 임박 | (당기순이익−영업CF)/자산총계 | 약함 |
| H4 무형자산 비중이 클수록 위험 | 무형/자산, 무형/매출 | 부분 |

- 연속형은 Levene 검정으로 등분산 확인 후 t-검정 또는 Welch 검정, 비정규 대비 Mann-Whitney U 병행
- **핵심 가설 H1은 1년 괴리·3년 누적 괴리 모두, t+1·t+2·2년 내 모든 시계에서 기각됨**
- 업종·연도 중앙값 대비 상대화도 효과 없음 (상대변수가 원변수와 VIF 90–290으로 사실상 동일)
- 살아남은 신호: 영업이익률(전 시계에서 가장 강함), 당기 손상 인식 여부,
  무형/영업현금흐름·무형/매출(약함)
- **당기 손상 인식 여부는 t+2 단독으로는 유의하지 않음(p=0.18)** — 손상 지속성은 1년짜리 현상임

## 6. 모델링

지표는 Accuracy를 배제하고 **Recall과 Average Precision(PR-AUC)** 을 사용함.
손상을 놓치는 2종 오류의 손실이 1종 오류보다 크고, 감사기준도 감사위험을 2종 오류로만 정의함.

분할은 **연도 분할**(과거로 학습해 미래 예측)과 **기업 분할**(기업 단위 누수 제거)을 모두 확인함.

| 분할 | 모델 | Recall | AP | ROC-AUC |
|---|---|---|---|---|
| 연도 | 당기 손상 인식 여부 하나만 | 0.438 | 0.632 | 0.571 |
| 연도 | 로지스틱 회귀 | 0.672 | 0.676 | 0.608 |
| 기업 | 당기 손상 인식 여부 하나만 | 0.491 | **0.649** | **0.679** |
| 기업 | 로지스틱 회귀 | 0.527 | 0.653 | 0.597 |

**변수 8개를 넣은 모델이 "작년에 손상했나?" 한 줄짜리 규칙을 이기지 못함.**
기업 분할에서 AP는 사실상 동일하고 ROC-AUC는 오히려 단일 변수가 더 높음.

또한 로지스틱 회귀의 **영업이익률 계수 부호가 단변량 검정과 뒤집힘**(오즈비 1.29).
322건에 변수 13개를 넣어 노이즈를 학습한 것으로 판단함. 목적이 "왜 위험한지 계수로 설명"이었으므로
계수를 신뢰할 수 없다면 모델을 쓸 수 없다고 결론함.

## 7. 한계

- **규모 편향**: 대사 성공률 대형 95.7% vs 소형–중대 78–82%. 완전히 제거하지 못함
- **표본 규모**: 390 firm-year / 56개사. 복잡한 모델을 쓸 수 없는 크기임
- **관측 불가능성**: 손상 인식 여부만 관측되고 '인식했어야 함'은 관측 불가.
  당초 설계한 '미인식 위험군 추출'은 모델이 성립하지 않아 수행하지 못함
- **해상도**: 기업 단위 집계. 판권·콘텐츠를 별도 컬럼으로 구분 공시하는 기업은 24%뿐
- **회계정책 차이**: 콘텐츠를 무형자산이 아니라 재고자산·선급금으로 분류하는 제작사가 있음
  (에이스토리 무형자산 비중 중앙값 0.026%). 같은 드라마 제작사라도 적용 대상이 아닐 수 있음

## 8. 감사 실무 관점의 인사이트

1. **공시 상세도 자체가 기업마다·연도마다 다름** — 스튜디오드래곤은 2022년까지 현금흐름표
   조정항목을 표시했다가 2023년부터 생략함. 본문만 보고 비교하면 비교가능성이 성립하지 않음
2. **주석과 본문의 대사가 유일한 검증 수단이었음** — 당기/전기, 연결/별도, 단위,
   취득원가/장부금액을 구분할 방법이 없었으나 본문 금액과 맞춰보는 것만으로 네 가지가 해결됨.
   감사에서 주석과 본문을 맞춰보는 절차가 왜 필요한지를 데이터로 경험함
3. **손상 지속성은 1년짜리 현상** — 감사 계획 시 주목 기간의 근거가 될 수 있음

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

DART OpenAPI 인증키가 필요한 수집 스크립트를 다시 돌리려면 `.env`에 키를 넣어야 함
(`.env.example` 참조). 대시보드는 `data/`에 커밋된 결과 파일만 읽으므로 키 없이 실행 가능함.

```
├── app.py                     Streamlit 대시보드
├── src/
│   ├── 01_fetch_corp_codes    기업코드 마스터 수집

│   ├── 10_note_extractor_reconciled   본문 대사 도입 (60%)
│   ├── 12_extractor_v3        느슨한 검출 + 2점 대사, 헤더 보정 (90%)
│   ├── 14_extractor_v4        정정보고서 폴백 (96%)
│   ├── 15–17_universe*        모집단 확정, 무형비중 게이트 폐기
│   ├── 18_collect_main        78개사 661 firm-year 본 수집
│   ├── 19–22_diagnose/verify  결측 편향 점검, 손상액 원표 대조
│   ├── 21_build_panel         연결/별도 전환 플래그, 적용범위 판정
```
